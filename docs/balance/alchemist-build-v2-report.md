# 《五行问道》角色构筑 V2 第二轮：丹修验证

## 实现范围

本轮只改丹修。丹修获得 0–8 炉火：打出施毒、灼烧、回春、治疗或翻倍中毒的牌后自动获得 1 点，单张牌合计最多获得 2 点；消耗炉火的终结牌不会自动返还炉火。旧存档在恢复战斗时补齐资源。剑修仍用剑意，体修未启用角色资源。

丹修专属牌由 3 张增至 9 张，分为万毒、焚炉、生生三条构筑：

| 体系 | 启动 | 终结 | 状态兑现 |
|---|---|---|---|
| 万毒 | 蚀骨丹 | 百毒归元 | 按毒层造成无视护甲的伤害，只移除一半中毒 |
| 焚炉 | 催火诀 | 赤炉焚天 | 先打普通攻击，再引爆并清空全部灼烧 |
| 生生 | 养元丹 | 青帝回天 | 消耗全部回春，回血并向随机敌人发出多段伤害 |

炉火至少 4 时，三张终结牌加强兑现并消耗 4 炉火。状态兑现不吃锐气、攻击遗物、克制或敌人护甲；青帝回天的随机目标使用对局种子。引毒诀仍是通用消耗牌。已给明确属于这些机制的旧牌加构筑标签；初始牌可产生炉火，但不计入奖励协同或成型统计。奖励协同只看当前角色的构筑标签，倍率仍为 1.25／1.4，上限 1.4；剑修与体修的奖励行为保持原样。

手机战斗界面显示朱红色八格炉火，卡牌和奖励标明构筑方向；手牌预览分别显示普通攻击、状态爆发伤害与治疗。毒爆、焚炉、生机化攻有独立提示和粒子演出，支持减少动态效果。

## 模拟口径与结果

完整对局使用 `node test/sim.js 3000 0` 和 `node test/sim.js 3000 5`。每个天劫档位，剑修、丹修、体修各 1000 局，种子 `10000 + 31 × i`。构筑报告使用 `node test/build-report.js 1000 0 alchemist` 和 `node test/build-report.js 1000 5 alchemist`。模拟器按即时价值出牌，奖励仍固定取第一张，不会主动规划丹修体系；第一幕机会按同体系奖励出现次数计，重复卡分别计数。

| 天劫 | 剑修（本轮／前轮） | 丹修（本轮／前轮） | 体修（本轮／前轮） | 卡死 |
|---:|---:|---:|---:|---:|
| 0 | 31.0%／31.0% | 35.8%／42.2% | 58.5%／58.5% | 0 |
| 5 | 10.0%／10.0% | 11.5%／17.0% | 26.4%／26.4% | 0 |

丹修下降 6.4／5.5 个百分点。新增牌扩大了卡池，而自动策略既固定拿第一张奖励，也不主动准备终结回合；该结果是平衡风险信号，不能单独代表人工构筑体验。本轮没有为了追平旧胜率而改动敌人或直接提高丹修数值。

| 丹修指标（每档 1000 局） | 天劫 0 | 天劫 5 |
|---|---:|---:|
| 第一幕同体系奖励出现 2–4 次 | 73.0% | 72.4% |
| 同体系奖励最多出现次数均值 | 2.2 | 2.1 |
| 万毒初步成型（非初始同标签 ≥4） | 0.7% | 0.5% |
| 焚炉初步成型 | 0.8% | 1.0% |
| 生生初步成型 | 0.7% | 0.5% |
| 任意完整成型（同标签 ≥6 且含 Rare 终结牌） | 0% | 0% |
| 最大毒／灼烧／回春层数 | 58／31／31 | 51／33／20 |
| 炉火到达 8 的对局 | 99.2% | 98.7% |
| 状态爆发总次数 | 1884 | 1476 |
| 最大单次爆发伤害 | 39 | 36 |
| 终结牌打出总数 | 2530 | 1989 |
| 单回合最高伤害 | 79 | 80 |

自动策略的最终同体系牌数偏低，因而不能把表中的自动成型率当成玩家主动选牌的成型率。炉火到顶比例很高，说明当前资源容易积累；人工试玩需重点判断等待终结牌期间的炉火管理是否仍有决策感。爆发伤害统计按目标实际剩余生命计，不含溢出伤害。

## 验证和试玩重点

- `npm test`：炉火获取、上限和隔离；毒爆、火爆、回春与护甲语义；旧存档；初始牌奖励权重；剑修回归；视觉清理与减少动态效果。
- `npm run sim` 和上述两档千局模拟：完整流程无卡死；剑修和体修结果与前轮一致。
- `npm run audit:mobile`：覆盖 360、390、393、430 像素视口，并单列丹修炉火八格检查。

下一步人工试玩应分别主动选万毒、焚炉、生生路线：记录第一幕能否拿到启动牌，何时拿到终结牌，毒爆后继续养毒与火爆清空之间是否有明确取舍，以及青帝回天是否同时产生有效治疗和可感知的多段伤害。
