# 《五行问道》角色构筑 V2 第三阶段：体修验证

## 实现与规则

体修获得 0–10 战势。只有敌方攻击被护甲实际抵挡才计入战势：同一敌方阶段每累计挡伤 5 点获得 1 点，最多获得 3 点；多段与多敌攻击共同累计。直接扣血、持续伤害和穿透攻击不会生成战势。战势跨回合保留，下一场战斗从 0 开始。敌方阶段只汇总提示一次，避免多段攻击时反复弹字；旧存档在恢复体修战斗时补齐资源。

体修专属卡由 3 张增至 9 张，三条构筑分别兑现不同资源：

| 构筑 | 启动 | 终结 | 主动代价 |
|---|---|---|---|
| 镇岳 | 镇岳桩 | 撼山式 | 按当前护甲增加攻击，随后失去一半护甲；热势消耗 4 战势 |
| 金刚 | 借力反震 | 金刚震怒 | 对所有敌人造成荆棘状态伤害，移除一半荆棘；热势消耗 4 战势 |
| 蓄势 | 抱元守一 | 崩天式 | 战势与锐气共同提高单击伤害，消耗全部战势 |

三张旧专属牌保留原有数值并加入构筑标签。少量明确契合机制的通用牌与初始牌也加入标签；初始牌不计入奖励协同和成型统计。三角色专属卡奖励基础权重统一为 3 × 1.3，同标签非初始卡达到 2／4 张时仍分别乘 1.25／1.4，最高 1.4。厚土保留 4 点护甲、敌人数值、地图、遭遇与其他角色牌面均未调整。

手牌与卡牌详情现在显示撼山耗甲、震怒每敌伤害与荆棘消耗、崩天战势消耗。三张终结牌共用终结演出入口，并有不同的体修粒子与冲击效果；荆棘震怒使用范围震波。手机界面的十格战势采用土金色岩纹。

## 自动模拟结果

完整模拟命令为 `node test/sim.js 3000 0` 和 `node test/sim.js 3000 5`，每个档位三角色各 1000 局，种子沿用既有报告。体修构筑报告命令为 `node test/build-report.js 1000 0 monk` 与 `node test/build-report.js 1000 5 monk`。模拟器仍按即时价值贪心出牌、固定选第一张奖励，不会主动追求某条构筑。

| 天劫 | 剑修 V2 | 丹修 V2 | 体修 V2／原基线 | 卡死 |
|---:|---:|---:|---:|---:|
| 0 | 31.0% | 35.8% | 52.9%／58.5% | 0 |
| 5 | 10.0% | 11.5% | 20.5%／26.4% | 0 |

体修自动胜率分别下降 5.6 和 5.9 个百分点，没有触及方案中 61.5%／29.5% 的过强警戒线。新增兑现牌会消费原本可用于防御的资源；自动策略也不会为终结回合保留护甲或选择同体系奖励，因此这组胜率不能替代真人构筑判断。

| 体修指标（每档 1000 局） | 天劫 0 | 天劫 5 |
|---|---:|---:|
| 第一幕同体系奖励出现 2–4 次 | 79.8% | 75.0% |
| 镇岳初步成型（同标签非初始 ≥4） | 0.7% | 0.9% |
| 金刚初步成型 | 3.4% | 3.3% |
| 蓄势初步成型 | 0.3% | 0.8% |
| 任意完整成型（同标签 ≥6 且持有 Rare 终结牌） | 0% | 0% |
| 单局护甲／荆棘／锐气／蓄势峰值 | 69／38／20／3 | 75／30／21／3 |
| 战势峰值 | 10 | 10 |
| 曾达到 10 战势的对局 | 78.4% | 86.5% |
| 挡伤总量／实际生成战势 | 458840／60599 | 479879／59452 |
| 战势浪费量／浪费率 | 5647／8.5% | 10872／15.5% |
| 撼山／震怒实际伤害总量 | 17938／9134 | 14548／6855 |
| 单回合峰值伤害／终结牌打出数 | 108／3874 | 125／3295 |

战势浪费率定义为“已达到每阶段最多 3 点的可得战势中，因资源上限而未能获得的份额”，即 `wasted / (generated + wasted)`；每阶段超过 3 点的挡伤和战斗已结束时不再结算的战势不计入分母。撼山实际伤害按目标扣除的生命计算，不包含溢出伤害。这个指标与 78%–87% 的满战势对局占比共同提示：自动策略时常积满战势却拿不到或不及时打出消费牌。自动完整成型率为零也主要反映固定拿第一张奖励的策略限制。

## 验证范围与待人工验收

- 156 项自动测试通过，覆盖挡伤累计、阶段上限、穿透和直接伤害排除、三种兑现的消费顺序、预览、旧存档、奖励权重及其他角色回归。
- `npm run audit:mobile` 覆盖 360、390、393、430 像素宽度，十格战势没有挤压头像或生命条；同时检查减少动态效果与特效节点清理。
- 尚未完成方案要求的镇岳、金刚、蓄势各 3 局人工主动构筑试玩。人工验收应特别观察护甲是否值得砸出、荆棘是否值得主动消耗，以及满战势等待终结牌的空窗。
