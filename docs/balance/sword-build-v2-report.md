# 《五行问道》角色构筑 V2 第一轮：剑修验证

## 本轮实现

本轮按实施方案第 73 节，仅完成通用角色战斗资源框架与剑修 V2。剑修每场战斗从 0 剑意开始，上限 10。攻击获得 1 点，续链与克制各额外获得 1 点，单张牌最多获得 3 点；资源变化和满值都发出事件。旧存档缺少战斗资源字段时，在读档时补齐。丹修与体修尚未启用新资源。

剑修原有三张专属牌增加构筑联动：万剑归宗在 5 剑意以上追加攻击，心剑续链时额外获得剑意，破军在 6 剑意以上增加伤害。新增六张专属牌，每条路线各一张灵品启动/循环牌和一张玄品收益牌：

| 构筑 | 灵品组件 | 玄品收益 | 玩法 |
|---|---|---|---|
| 金锋·剑意 | 凝锋诀 | 一剑开天 | 攒剑意后一次消耗，8 点以上贯穿护甲 |
| 流云·循环 | 行云诀 | 沧浪连斩 | 续链过牌、条件回灵，按本回合已出牌数强化连斩 |
| 金水·连携 | 金水引 | 天河剑阵 | 金牌调整连携，再用水牌多段收益 |

行云诀每场战斗仅能打出一次，避免与抽牌、回灵卡形成无限循环。一剑开天消耗全部剑意，本次攻击也不返还基础剑意；万剑归宗和破军保留剑意，三种收益的取舍不同。原角色被动未改，通用五行牌保留。

奖励仍按原稀有度抽取，剑修专属牌沿用原有权重 3 再乘 1.3；已有 2 张同标签牌时，同标签候选再乘 1.25，已有 4 张时乘 1.4，封顶 1.4。丹修、体修的奖励权重保持原值。标签只用于奖励、显示和统计，不直接改变战斗。手机奖励和桌面卡面显示“剑意／流云／金水”构筑提示。

剑修终结牌增加专属飞牌与命中演出，剑意达到上限时资源条高亮；单次伤害达到 40 的数字放大。动效遵守减少动态效果设置。

## 测试与模拟口径

完整对局使用 `node test/sim.js 3000 0`、`node test/sim.js 3000 5`：每个天劫档位，剑修、丹修、体修各 1000 局，种子 `10000 + 31 × i`。构筑报告用 `npm run report:build -- 1000 0` 和 `npm run report:build -- 1000 5`。模拟器照旧固定拿第一张奖励牌，并按即时估值贪心出牌；它不会主动挑选或规划三条构筑。

| 天劫 | 地图 V2 基线剑修 | 本轮剑修 | 丹修 | 体修 | 异常／卡死 |
|---:|---:|---:|---:|---:|---:|
| 0 | 35.0% | 31.0% | 42.2% | 58.5% | 0 |
| 5 | 12.2% | 10.0% | 17.0% | 26.4% | 0 |

丹修、体修的结果与地图 V2 基线逐项一致。剑修下降 4.0 和 2.2 个百分点，需要在人工选牌试玩中复核；本阶段未用单纯加伤害的方法追平胜率。

| 指标 | 天劫 0 | 天劫 5 |
|---|---:|---:|
| 第一幕同体系奖励出现 2–4 次的对局 | 74.7% | 73.5% |
| 最多同体系奖励出现次数均值（第一幕） | 2.4 | 2.3 |
| 金锋初步成型（同标签 ≥4） | 1.5% | 1.1% |
| 流云初步成型 | 0.3% | 0.3% |
| 金水初步成型 | 1.9% | 1.0% |
| 任意完整成型（同标签 ≥6 且含终结牌） | 少于 0.2% | 0% |
| 单局最高回合伤害均值 | 53.1 | 48.6 |
| 单回合打出至少 7 张牌的对局 | 8.1% | 5.2% |
| 剑意到达 10 的对局 | 91.9% | 89.2% |
| 终结牌打出总数 | 4717 | 3807 |

“初步成型”和“完整成型”是最终牌组的统计标准。第一幕同体系奖励按出现次数计，同一张牌重复出现会分别计数，因此该指标代表选择机会，不代表不同组件数。自动策略固定拿第一张牌，因而**同体系牌有多次出现机会，但真正拿齐同标签牌的比例很低**；这不能代替玩家主动选牌的成型率。峰值伤害是模拟事件记录的每回合对敌显示伤害合计，包含多目标和可能的溢出伤害；它用于比较高光频率，不代表单目标有效伤害。天劫 0 样本的最大单回合伤害为 128，最多单回合出牌 11 张，未出现卡死。

## 回归和后续验收

- `npm test` 覆盖剑意获得、上限、消耗、旧存档、三条牌组标签、奖励倍率、终结演出、统计复现及原有玩法。
- `npm run sim` 和两档 3000 局模拟用于检查流程与胜率。
- `npm run audit:mobile` 覆盖 360、390、393、430 像素手机布局；剑意条与奖励说明无横向溢出。

本轮仍需 5–10 局人工试玩，重点记录第一幕是否能明确选择一条路线、终结牌是否有可启动的前置组件、剑意满值却没有消费牌的频率，以及金水连携的出牌顺序是否有吸引力。若玩家有意选牌后仍难成型，再调整奖励或卡池；不要直接根据固定拿第一张牌的模拟器提高协同倍率上限。
