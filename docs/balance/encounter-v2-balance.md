# 《五行问道》遭遇系统 V2 双怪生命倍率平衡测试

## 1. 测试配置与口径

- 正式扫描：普通双怪 `hpScale` 依次设为 **0.45、0.50、0.55、0.60**；天劫 **0、5**；每组剑修、丹修、体修各 **1000 局**，共 **24000 局**。
- 分幕复核：以 0.45/0.45/0.45 为基线，追加 **0.50/0.45/0.45** 和 **0.50/0.55/0.60**，同样各角色、各天劫 1000 局，共 **18000 局**。
- 每组使用同样的角色和种子：`10000 + 31 × i`（`i = 0…999`，范围 10000–40969）。出牌、选路和购物策略完全复用 `test/sim.js`；种子相同不保证后续路径完全相同，因为不同战斗结果会改变随机数消耗和决策。
- 本节及后续历史扫描在模拟进程内覆盖普通双怪的 `hpScale`；当时单怪、精英、Boss、遭遇权重、敌人基础数值、AI 与游戏源数据均未改动，每组结束后恢复原值。报告末尾记录了之后正式落地的第一幕数值。
- **净耗血** = 进战生命 − 战后生命，战斗中治疗和战斗结束遗物效果可能使它为负。**承伤** = 引擎 `stats.damageTaken` 增量 + 战斗事件中 `directPlayerDamage` 的数值，包括中毒、灼烧、诅咒和自损，未扣除战斗内治疗；致死一击可能包含超过剩余生命的伤害。故净耗血用于观察总体资源变化，承伤用于观察承受的攻击与持续伤害，两者须并看。**同阶段承伤比**在同幕、同阶段比较单怪与双怪，再按双怪样本数加权；全局净耗血比受阶段分布和治疗影响，不单独作为调参门槛。
- “无净损”按战后生命不低于进战生命统计；汇总数据还单列 `exactNoLossRate`（净耗血恰好为 0）与 `damageFreeRate`（本场承伤为 0）。死亡率是到达该战斗的样本条件死亡率，不能直接当作所有开局玩家的死亡概率。模拟器是固定贪心策略，不能代替真人对优先击杀目标和机制互动的判断。
- `--quick` 只在终端打印；完整的 1000 局统一与分幕配置写入下述固定结果文件。其他自定义参数采用独立文件名，避免覆盖报告引用的数据。

运行命令：

```bash
npm test
npm run balance:encounters -- --quick
npm run balance:encounters
npm run balance:encounters -- --scales 0.45 --act-scales '0.50,0.45,0.45;0.50,0.55,0.60'
```

完整汇总见 [统一倍率数据](encounter-v2-results.json)和[分幕倍率数据](encounter-v2-mixed-results.json)。正式扫描与分幕复核均无卡死或异常退出。

## 6. 推荐参数与依据

**历史扫描推荐：第一幕 0.50，第二幕 0.45，第三幕 0.45。** 这一建议随后正式应用；以下理由保留原扫描时的比较口径。

理由：

1. 第一幕 0.45 的双怪在 mid 的平均净耗血 **1.04**，低于同阶段单怪 **2.47**；late 也为 **0.83 对 1.04**。升至 0.50 后，late 双怪净耗血变为 **1.46**、平均回合从 **2.26** 升至 **2.43**，基础难度和天劫 5 的总通关率几乎不变（**55.2%→55.3%**、**23.7%→23.4%**）。
2. 第二幕与第三幕在 0.45 已有明显伤害、死亡和资源压力。统一升至 0.55/0.60 会增加中后期死亡，天劫 5 总通关率分别降到 **21.1%/19.7%**；分幕 0.50/0.55/0.60 也只有 **21.0%**。
3. 第三幕最危险的组合出现在 mid，值得日后针对具体遭遇做复核，而不应整体抬高第三幕双怪生命。当前模拟还显示角色差距超过建议警戒线，调怪物倍率不能解决角色间的全部平衡问题。

本次数据回答的是固定模拟策略下的数值压力。推荐值应在实际改动后用真人试玩检查怪物意图、目标优先级和体感节奏，再以相同脚本回归通关率和高风险遭遇。

## 8. 高风险遭遇的击杀顺序诊断

平衡模拟器现记录双怪的首次与第二次击杀、同一次行动结算双杀，以及玩家死亡时仍存活的敌人。下表是**正式配置、天劫 5** 的结果。首次击杀一列的计数以遭遇次数为分母；“死亡时存活”以该遭遇中的玩家死亡次数为分母，两只怪的计数可以相加超过死亡次数。

| 遭遇 | 出现 | 玩家死亡 | 平均回合 | 首次击杀 | 玩家死亡时存活 |
|---|---:|---:|---:|---|---|
| 黄泉土偶＋雷兽 | 158 | 70（44.3%） | 4.77 | 黄泉 100；雷兽 4；同时 3；未击杀 51 | 黄泉 51/70；雷兽 69/70 |
| 天兵＋星火灵 | 145 | 43（29.7%） | 4.05 | 天兵 110；未击杀 35 | 天兵 35/43；星火灵 41/43 |
| 玄冰蛟＋星火灵 | 185 | 47（25.4%） | 4.10 | 玄冰蛟 146；同时 2；未击杀 37 | 玄冰蛟 37/47；星火灵 47/47 |
| 古木魍＋黄泉土偶 | 191 | 43（22.5%） | 5.35 | 古木魍 169；未击杀 22 | 古木魍 22/43；黄泉 43/43 |
| 尸藤＋血煞 | 207 | 22（10.6%） | 4.15 | 尸藤 200；未击杀 7 | 尸藤 7/22；血煞 22/22 |

黄泉土偶＋雷兽仍是最高优先级：158 次遭遇中死亡 70 次，其中 51 次在击杀任一敌人前死亡；70 次死亡里雷兽仍存活 69 次。**这些数字不能证明雷兽是正确的首杀目标**：当前模拟策略总是攻击第一只存活敌人，极少主动先打雷兽（仅 4 次）。其他组合也呈现同样的首位目标偏向。以黄泉土偶＋雷兽为例，先杀黄泉的 100 场中有 19 场后续死亡，但先杀雷兽仅有 4 场，样本不足以比较两种目标策略。双杀按同一次模拟动作结算归类，包括群攻与同一敌方回合内的连续结算。

因此本次**不削弱**这五个组合。后续真人试玩应重点检查目标提示是否清晰、优先击杀是否改变结果，以及正确处理后是否仍有合理胜率；需要调数值时，再针对单个遭遇做小步调整。
