# 《五行问道》地图生成 V2 验证报告

## 实现与统计口径

地图仍为 8 层普通节点加第 9 层幕主，沿用原节点数、邻层连线和 seeded RNG。普通节点按横向位置标记稳健、机缘、险途；节点类型由基础权重乘路线倍率，再受阶段、连续节点和全幕数量限制。保底宝箱在第 4–6 层加权抽取，机缘节点单点权重为 3，稳健为 2，险途为 1。幕主前的第 8 层固定两处休整。

按种子 `20000…21999` 对三幕各生成 2000 张地图，共 **6000 张**。每张均通过 `validateMap()`，未出现不可达节点、死路、连续同类特殊节点或超额配额。

## 完整游戏模拟

正式配置下使用 `node test/sim.js 3000 0` 和 `node test/sim.js 3000 5`。每档、每角色各 1000 局，种子 `10000 + 31 × i`。修改前基线用当前提交的原地图生成器在同一套游戏数据、同一种子上重新运行得到，与[遭遇系统正式配置报告](encounter-v2-balance.md)一致。模拟器的选路、出牌、购物策略均未修改。

| 天劫 | 地图 | 总通关率 | 剑修 | 丹修 | 体修 | 卡死 |
|---:|---|---:|---:|---:|---:|---:|
| 0 | 原地图 | 55.3% | 45.9% | 51.9% | 68.1% | 0 |
| 0 | V2 | 45.2% | 35.0% | 42.2% | 58.5% | 0 |
| 5 | 原地图 | 23.4% | 14.5% | 24.7% | 31.1% | 0 |
| 5 | V2 | 18.5% | 12.2% | 17.0% | 26.4% | 0 |

天劫 0 下降 10.1 个百分点，天劫 5 下降 4.9 个百分点。基础难度超过方案中的 5 个百分点分析警戒线，丹修在天劫 5 也下降 7.7 个百分点。各角色强弱次序未变，但下降需要在真人试玩中重点复核。

主要机制原因是保底宝箱不再固定于左侧第 5 层。相同 3000 局天劫 0 样本中，模拟器每幕约有 5.7–6.2 次选择稳健节点，机缘仅约 0.8–0.9 次；它优先选当前可见的节点类型，不会提前规划通往中路宝箱的连线。原地图第一幕实际拿到宝箱平均 1.262 次，V2 为 0.935 次；普通战斗从 3.221 次增至 3.764 次。第二、三幕也呈现宝箱减少、普通战斗增加的方向。**这是真实的地图资源分布变化，也受到模拟器左路偏好放大；不能直接把通关率当作真人胜率。** 本阶段保留模拟 AI 与战斗数值，避免用无关规则抵消地图改动。

## 回归与移动端

- `npm test`：115 项通过，包括 3000 张地图的逐张约束检查、路线统计测试、确定性和旧存档读取。
- `node test/sim.js 3000 0`、`node test/sim.js 3000 5`：各 3000 局，均无卡死。
- `npm run audit:mobile`：360×640、390×844、393×852、430×932 的页面布局审计通过；地图起点标签、路线说明、地图连线均无横向溢出。

后续真人试玩应特别记录三条路线的实际选择比例、每幕获得的宝箱数，以及第二、三幕结束时的生命和牌组成长。若真实玩家也出现相近幅度的下降，再单独做地图资源平衡调整。
